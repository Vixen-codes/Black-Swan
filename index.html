03

Model notes

Historical data
Prices are loaded from Yahoo Finance and aligned to a common daily frequency using forward filling.

Return model
Simple historical returns are converted to log returns for compounding.

Correlation
The historical covariance matrix is used to correlate simulated asset shocks. Near-singular matrices are repaired.

Limitations
V0.1 assumes correlated Gaussian returns. Fat tails, regime changes and bootstrap methods are not yet modelled.
