Most of what happens to a portfolio is ordinary. This tool is built for the rest of it.

What's built, what's next

This is an early build. The engine works end to end, but the return model is still the simple case.

  • shipped
    Correlated Gaussian simulation. Historical prices from Yahoo Finance drive a correlated log-return Monte Carlo across the whole portfolio.
  • shipped
    Ticker search. Look up holdings by company name instead of memorising exchange codes.
  • shipped
    Inline definitions. Every input and every result carries a plain-language explanation on hover.
  • building
    Fat-tailed returns. Swapping the Gaussian assumption for a Student-t or historical bootstrap model, so extreme moves show up more realistically.
  • building
    Regime detection. Letting volatility and correlation shift between calm and crisis regimes instead of staying fixed for the whole horizon.
  • building
    Backtested calibration. Checking simulated tail estimates against what actually happened historically.
Black Swan is a research build, not financial advice v1.1
